LOCK SUMMARY
================================================================================

1. Player weapons do not use a conventional permanent exact ammo counter as the baseline presentation.

2. For compatible magazine-fed weapons:
- tap reload performs the normal context-sensitive reload / recovery action;
- hold reload performs a magazine/ammunition-state inspection when mechanically valid;
- the weapon-inspect view may expose the same information through a contextual prompt.

3. Carried magazines are represented individually by magazine silhouettes/shapes rather than exact round numbers.
- full magazine = full shape fill
- partial magazine = partial shape fill
- empty retained magazine, if retained = empty outline
The underlying simulation still tracks exact cartridges; the player-facing display deliberately does not.

4. Each magazine identifies its ammunition type. Type switching remains a physical magazine-change action, not an abstract instant toggle.

5. Retained partial magazines remain usable. If the only loadable magazine is partial, the character loads it and uses the remaining rounds. The system must never report an empty weapon while compatible usable ammunition remains.

6. Default automatic magazine selection is FULLest-first within the currently selected ammunition type. The character loads the fullest usable magazine first, then works downward through progressively less-full magazines. Equal-load magazines may use pouch/inventory order as a tie-breaker. Deliberate inspect-view selection may override the automatic choice where supported.

7. When all magazines of the currently preferred ammunition type are exhausted, reload automatically falls back to another compatible ammunition type still carried by the player. Within the fallback type, the fullest usable magazine is selected first; a partial fallback magazine remains valid.

8. Automatic fallback must never select incompatible ammunition. The type change should be communicated through restrained labels, magazine appearance, handling cues, and the resulting ballistic/acoustic behavior rather than a large modal alert.

9. Chamber state remains mechanically distinct from magazine state. A chambered round is still real even when the magazine is empty or removed, where the weapon permits it.

10. The magazine-silhouette grammar applies primarily to detachable-magazine-fed weapons. Tube-fed, belt-fed, revolver, internal-box, single-shot, launcher, and other feed systems require platform-authentic equivalents.

11. Accessibility should favor clearer qualitative state rather than making a permanent exact numerical counter the default. Exact-count support, if ever offered, remains an optional accessibility decision rather than the baseline HUD language.
