## Editing rule

1. Make or land the durable change in `dev_src_docs/`.
2. Add or refresh the relevant synthesis layer here.
3. Update governance files when inventory or retirement state changes.
4. Refresh the archival master at milestones rather than after every small pass.

If a compendium body conflicts with a later canon lock or dated addendum, the later explicit owner decision and source-landed correction control.
