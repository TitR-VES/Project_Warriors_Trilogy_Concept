# Publishing to GitHub Wiki

**The GitHub Wiki feature is currently disabled for this repository.** This branch contains Wiki-ready Markdown in `wiki/`, but it is not a live GitHub Wiki. The available connected GitHub actions cannot enable the feature or push directly to the separate Wiki Git repository.

To publish, enable **Settings → General → Features → Wikis**, initialize the Wiki, and transfer these Markdown files into the repository's separate `Project_Warriors_Trilogy_Concept.wiki.git` Git repository. Keep `Home.md`, `_Sidebar.md` and `_Footer.md` as named. Commit/push and test all navigation/source links. Update the primary source files before future wiki revisions.
