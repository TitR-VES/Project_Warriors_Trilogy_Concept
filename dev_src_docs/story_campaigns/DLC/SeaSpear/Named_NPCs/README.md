# Named NPC source homes

This directory contains ontology-backed source homes for named non-player characters with source-backed presence in this installment or DLC.

Use one directory per stable `PW-NPC-*` identity. Directory names combine the stable ID with a portable ASCII name slug. Canonical spelling and story meaning remain controlled by the named-NPC ontology.

Put character-specific profiles, NPC-focused continuity, branch-state, equipment, voice, and presentation pages in the appropriate identity directory. Keep campaign-wide, team-wide, multi-character, chronology, provenance, and governance material in `../Shared/`.

The controlling catalog is `dev_src_docs/canon_lore_source_of_truth/ontology/pw_named_npc_catalog_rev1.yaml`.
