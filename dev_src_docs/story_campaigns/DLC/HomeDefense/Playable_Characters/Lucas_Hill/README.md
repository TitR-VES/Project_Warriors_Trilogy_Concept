# Playable-character source home

This directory is the durable campaign-source home for an ontology-listed playable point of view.

Place character-specific mission, scene, arc, continuity, presentation, and campaign-role source pages here. Put installment-wide, multi-character, or campaign-governance material in the sibling `Shared/` directory instead.

The absence of additional files means that no dedicated campaign-specific source page has landed here yet; it does not mean the playable character is absent from the campaign.
