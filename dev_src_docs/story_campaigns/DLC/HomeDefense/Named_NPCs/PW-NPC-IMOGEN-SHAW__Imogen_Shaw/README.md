# Named NPC source home

This directory is bound to the stable `PW-NPC-*` identity embedded in its directory name.

Use it for durable installment-specific character profiles, NPC-specific scene or mission-presence notes, voice and behavior references, equipment continuity, branch-state references, and presentation material.

Do not duplicate campaign-wide or team-wide packets here. Preserve branch-dependent outcomes and unresolved fields unless a controlling source explicitly selects or resolves them.

Canonical spelling, aliases, campaign references, and appearance state remain controlled by `dev_src_docs/canon_lore_source_of_truth/ontology/pw_named_npc_catalog_rev1.yaml` and its segmented entity and appearance files.
