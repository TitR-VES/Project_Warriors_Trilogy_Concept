# Playable character source homes

This directory contains durable source homes for characters who are playable in this installment or DLC.

Put campaign architecture, mission scripts, perspective-specific mechanics, playable-character loadout continuity, and POV-specific presentation in the relevant character directory.

A character who is playable here remains in `Playable_Characters/` even when the named-NPC ontology records that person in an NPC state elsewhere. Do not duplicate the same source page into `Named_NPCs/`.

Keep campaign-wide, team-wide, multi-POV, chronology, provenance, and governance material in `../Shared/`.
