FIXED ALARM NETWORK

The compound contains four fixed alarm buttons:

1. NORTH SERVICE ENTRANCE
   Mounted beside the north main administration-building service entrance.

2. EAST GATE GATEHOUSE
   Located inside the east gate gatehouse.

3. WEST GATE GATEHOUSE
   Located inside the west gate gatehouse used by the football-watching guard.

4. MANAGER'S-OFFICE HALLWAY
   Mounted in the first-floor hallway leading to the manager's office inside the
   main administration building.

A guard or the manager can use any accessible alarm button to alert all other
security personnel on the base to Victor Two Bravo's presence.

RADIO DISTRIBUTION

All seven armed contractors carry radios. The shell-company manager also carries a
radio. The total number of radio-equipped alert-capable characters is therefore
eight:

- east-gate guard;
- west-gate guard;
- east-berth guard;
- north-jetty guard;
- north-service-entrance / corridor guard;
- two manager's-office guards;
- the manager.

Any of these characters can use a radio to alert the other security personnel on
base to the player's presence.

ALERT FUNCTION

Fixed alarm activation and a completed radio alert serve the same narrative and
systemic purpose: the remaining security personnel on base become aware that Victor
Two Bravo is present and the covert infiltration enters a compound-alert state.

This source establishes an internal base alert only. It does not by itself lock
outside police response, off-site reinforcements, military response, or a wider
island-wide alarm network.

DESIGN INTENT

The system is deliberately redundant:

- fixed buttons create readable spatial alarm objectives;
- radios make every guard and the manager a mobile alert risk;
- controlling one gatehouse or one administration-building alarm does not disable
  every other alert channel;
- the player must manage witnesses and communication opportunities rather than only
  avoid a single central alarm console.

The west-gate guard's football viewing, bathroom absence, and flask break remain
valid infiltration windows, but catching him away from the west gatehouse does not
remove his radio capability.
